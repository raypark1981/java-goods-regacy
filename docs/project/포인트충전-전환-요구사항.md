## SFR-033-01 · 포인트 자동충전

**출처:** RFP &nbsp;|&nbsp; **수용여부:** 수용

### 상세내용
- 자동 포인트 충전 결제 (h.point와 동일)
- 계좌와 연동하여 자동충전 설정 기능 추가
- 포인트 결제시 부족분만큼 자동 충전 (5만원 이상, 1천원 단위)

### 코멘트
- **TOSS 페이먼츠 자동빌링 API 연동**
- 계좌와 연동하여 자동충전 설정 기능 추가
- 개좌 등록/수정/삭제
- 결제 비밀번호 관리 (등록, 변경, 찾기)
- 결제 자동충전 기능 — 결제 포인트 부족시 충전 후 결제 (기본 5만원, 1천원 단위)
- 잔액 자동충전 기능
  1. 특정 일자에 특정 금액 자동 충전 : 매월 N일, 5만원 이상 1천원 단위 → 선불충전 서비스 중 하나
  2. 특정 포인트 이하일 경우 특정 금액 자동 충전 : 설정한 포인트 이하일 경우, 설정 금액까지 5만원 이상 1천원 단위로 산정하여 충전
- 결제 계좌 선택, 결제 비밀번호 입력 (5회 이상 오류시 차단)

## SFR-033-03 · 캠페인 연동

**출처:** RFP

### 상세내용
- 캠페인 기능 연동
- 자동 충전 포인트로 충전/첫 충전 시 추가 리워드 적립
- 충전 포인트로 결제 시 랜덤 박스 경품 제공 (포인트, 쿠폰, 플러스포인트)

### 코멘트
- 캠페인 기능 연동
- 자동 충전 포인트로 충전/첫 충전 시 추가 리워드 적립
- 충전 포인트로 결제 시 랜덤 박스 경품 제공 (포인트, 쿠폰, 플러스포인트)
- 랜덤 박스 충전 포인트 금액 구간대별 프로모션 적립률 상이 (ex. 10만원 미만 1%, 10만원 이상 5%)
- 계좌 충전 Y 대상자에게만 프로모션 진행
- **[기획/디자인]** 랜덤박스로 제한하지 않고 다양한 혜택을 주는 방향으로 생각 중

## SFR-035-09 · 모바일상품권 충전

**출처:** 현업(액션)

### 상세내용
- 충전 화면 월페이지 운영 : 상품권 번호 인식하여 발행사/주제 자동 인식 (나이스, 머니트리, 11번가 외)
- 충전 완료 후, NCP 추천 상품 연동 (heydi)
- 충전 완료 후, 매핑되어 있는 오퍼 (쿠폰, 플러스포인트 등) 발급 여부 노출

### 코멘트
- **[기획/디자인]** IT사업부에서 기 작업 중인 내용임 — 영향 없음

## SFR-070-01 · 포인트 전환

**출처:** 현업(액션)

### 상세내용
- h.point로 전환 기능 (전환 가능 포인트 조회/새로고침, 일괄/개별 전환, 미가입 제휴사 가입하기 버튼)
- 전체 포인트 조회시 등의 프로세스 개선
- 제휴사 포인트로 전환 기능 (개별 전환)
- 전환 가능한 제휴사 검색 기능

### 코멘트
- **[기획/디자인]** IT사업부에서 기 작업 중인 내용임 — 영향 없음
- **[모바일]** 포인트 전환마다 제휴사 동의 등 1회만 받도록 수정 필요. 사용자가 포인트 전환 제휴사에 가입이 되어 있지 않은 경우 제휴사로 이동 링크로 전송하여 가입을 유도하도록 함
