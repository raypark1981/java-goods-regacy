## 7. SQL 규칙

- **queryId**: `DAO명.쿼리명`
- 쿼리 첫줄에 queryId 주석 기입
- **JOIN 스타일**: 신규 쿼리는 ANSI JOIN으로 작성. 수정 쿼리 전체를 ANSI 스타일로 변경할 필요는 없음

```xml
<select id="APAPntSwtcDAO.selectH000PntCI" parameterType="Map" resultType="HdgmMap">
  <![CDATA[
  SELECT /* PointTransitDAO.selectH000PntCI */
        , CI_VAL
        , TO_CHAR(sysdate, 'MMDD') || SEQ_AP_PNT_EXCH_HIS_01.NEXTVAL AS FLW_NO
    FROM (SELECT MCUST_NO, CI_VAL, DRDT_CNFM_DT
            FROM CU_CUST_CI_INF
          UNION ALL
          SELECT MCUST_NO, CI_VAL, DRDT_CNFM_DT
            FROM CU_DORM_CUST_CI_INF)
   WHERE MCUST_NO = #{mcustNo}
     AND ROWNUM = 1
  ]]>
</select>
```

## 8. 로그 규칙

- **`logger` 활용, `System.out` 사용 금지**
- 공통 항목: 시간, traceId, package/method
- 메시지 포맷: `log4j.xml`로 관리

### 레벨별 기준

| 레벨 | 사용 기준 |
|---|---|
| `DEBUG` | 메서드 시작/끝 |
| `INFO` | request/response(DML API), 외부 시스템 통신, 데이터 흐름(중간 계산값), 쿼리 바인딩 파라미터, API 처리시간, 설정 로딩 정보, 주요 구성 변경 감지 |
| `WARN` | 실패 후 재처리 성공, fallback 로직으로 자체 성공, 수행시간 임계치(3~5초) 초과, deprecated API 호출 |
| `ERROR` | Exception, 비즈니스 실패(5xx/4xx), 트랜잭션 롤백, 데이터 정합성 훼손, 시스템 장애(DB·외부 연동 API) |

### ERROR 로그 필수 포함 항목
- stack trace
- URL, HTTP method, status, 호출 IP, userAgent

### 민감정보 로깅 금지
- 주민번호, 카드번호, 토큰, 패스워드

### 로그 포맷 예시
```
[trd_hg][{traceId}] [${ctl}] [info] {hmbl.co.util.PageInfoInterceptor:39} 메시지
```

## 11. Git / 브랜치 / PR 규칙

### 브랜치 역할

| 브랜치 | 역할 |
|---|---|
| `master` (U2L-master) | 운영 서버 |
| `develop` | 개발 서버 |
| `stg` | 스테이징 서버 |
| `feature/*` | 로컬 개발 브랜치 |

### 브랜치 흐름

```
master
  └─ 1. feature 브랜치 생성 (기능 개발 시)
         │
         ├─ 테스트 pass
         │
         └─ 2. Merge → develop (Maven 빌드/테스트)
                          │
                          ├─ 테스트 pass
                          │
                          └─ 3. Merge → stg (공통 통합 테스트)
                                          │
                                          └─ 4. Merge → master (운영 서비스 반영)
```

### 환경파일 분리

| 환경 | 파일 |
|---|---|
| 로컬 | `.dev` |
| 스테이징 | `.stg` |
| 운영 | `*.prd` |
