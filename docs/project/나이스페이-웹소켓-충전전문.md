# 나이스페이 웹소켓 충전 전문

> **용도**: 나이스페이 선불카드/상품권 충전 요청 전문 정리  
> **전문코드**: `0105`  
> **전문명**: Online_충전  
> **연동 방식**: 웹소켓 통신 추정  
> **비고**: 첨부 이미지 기준으로 판독한 내용이며, 일부 샘플 전문은 원본 엑셀/전문 정의서로 재확인 필요

## 요청 흐름 메모

자동충전 결제 흐름에서는 토스 빌링 결제가 성공한 뒤, Java API 서버가 NICE 웹소켓 충전 전문을 호출하는 위치에 들어간다.

```text
OTC 승인 서버 요청
 → Java 자동충전 결제 API
 → 토스 빌링 결제 성공
 → NICE 웹소켓 충전 전문 요청
 → NICE 충전 성공 시 OTC 포인트 사용 요청
 → NICE 충전 실패 시 토스 결제 취소
```

## 확인 필요

| 항목 | 확인 내용 |
|---|---|
| 전문 원문 | 요청/응답 샘플 전문은 이미지 해상도상 전체 판독이 어려워 원본 엑셀 기준 확인 필요 |
| Header | `niceHeader`, `serviceHeader` 상세 필드 정의 필요 |
| 취소 공통 | `cancelRequest` 16자리 상세 필드 정의 필요 |
| 오류 응답 | 실패 시 응답 코드/메시지 필드 위치 확인 필요 |
| 결제수단 | 자동충전 토스 계좌 결제 후 NICE 충전 시 `payCode` 값을 무엇으로 보낼지 확인 필요 |
